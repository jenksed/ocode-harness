# Program Intent

Ocode exists to make agent-assisted engineering dependable enough for sustained real work without transferring human decision authority to models, mutable development state, or opaque automation.

The program protects these owner-level properties:

- agents operate through explicit capability, authority, permission, and evidence boundaries;
- planning decomposes work but does not authorize it;
- implementation, verification, independent review, acceptance, qualification, and release promotion remain distinct states and responsibilities;
- the repository is persistent program memory for current reality, intent, evidence, provenance, decisions, dependencies, and next-work eligibility;
- unknown or stale state is surfaced rather than guessed away;
- the normal operator runtime is an exact immutable stable release independent of the checkout being modified;
- candidates are exact, explicitly selected, qualified and dogfooded before promotion;
- failed and superseded work remains inspectable provenance;
- mechanisms may evolve when evidence changes, while protected properties remain stable unless the owner explicitly supersedes them;
- mature operation is proven through real projects, restart/recovery, upgrade/rollback, and bounded human-operable failure handling rather than test count or roadmap completion percentage.

Agents may propose changes to this intent. They may not silently redefine it. Any change to these protected properties requires explicit owner authority and a recorded supersession decision.
