# Adversarial Review

Use only the supplied bounded review scope. Independently inspect implementation and evidence; challenge correctness, governance, authority, and evidence sufficiency. Tie findings to evidence, distinguish demonstrated defects from concerns, state materiality, and return an evidenced ACCEPT, REPAIR, or BLOCKED result. Do not invent defects, mutate source, or perform repair. Return ReportedEvidenceCapsule v1 and stop after sufficient bounded challenge.
