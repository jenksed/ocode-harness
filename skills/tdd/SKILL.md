# TDD

1. Load and follow tdd.
2. Use only supplied bounded context.
3. Run the focused repository test before implementation mutation.
4. If it initially passes, stop with RED_NOT_ESTABLISHED.
5. After RED, make the smallest authorized implementation change.
6. Run the same focused test again and require GREEN.
7. Do not stage, commit, push, or use external research.
8. Do not broaden context without an authorized recorded expansion.
9. Return ReportedEvidenceCapsule v1 and stop once evidence is sufficient.
